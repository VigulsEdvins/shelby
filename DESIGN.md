## Brand & Style

This design system embodies high-velocity growth marketing and autonomous intelligence. Tailored for media buyers, growth engineers, and digital founders running mission-critical Meta Ads and WhatsApp conversational funnels, it exudes decisive performance, algorithmic precision, and effortless conversion.

The style combines the crisp architectural minimalism of Stripe with the radiant energy of conversational conversion engines. Pure stark blacks are eliminated in favor of nuanced slate tones, paired with luminous WhatsApp emerald energy. The visual tone is technical yet immediately legible: high-density performance telemetries, real-time conversion triggers, and autonomous agent confidence communicate that spend is constantly optimized and active 24/7.

## Colors

The palette establishes an ultra-clean, luminous environment built on crisp off-white layers and calibrated emerald signals:

- **Primary (`#25D366`)**: Signature WhatsApp neon green. Used deliberately for primary calls to action, real-time autonomy statuses, live conversation ticks, and affirmative conversion events. In light mode, it generates subtle radiant halos (`rgba(37, 211, 102, 0.22)`) rather than overpowering flat slabs.
- **Secondary (`#0F172A`)**: Deep Obsidian Slate. Serves as the primary anchor for maximum contrast headlines, dominant navigational shells, and high-impact hero interaction zones.
- **Tertiary (`#059669`)**: Deep Emerald. Provides balanced optical contrast for text links, data trend upward indicators, active state outlines, and badges that require deep legibility against light backgrounds.
- **Neutral (`#64748B`)**: Balanced Slate. Coordinates layout lines, tertiary metrics, table headers, and inactive meta copy.

### Canvas & Surface Hierarchy
- `surface-base`: `#F8FAFC` (Canvas background)
- `surface-card`: `#FFFFFF` (Elevated modules, primary data panels)
- `surface-subtle`: `#F1F5F9` (Nested input wells, agent dialogue backdrops)
- `border-subtle`: `#E2E8F0` (Default panel separation)
- `border-strong`: `#CBD5E1` (Focused state delineation, active card perimeters)
- `text-primary`: `#0F172A`
- `text-secondary`: `#334155`
- `text-muted`: `#64748B`

## Typography

The type system blends the computational, forward-leaning geometry of **Space Grotesk** with the surgical reading clarity of **Geist**.

- **Space Grotesk** is reserved for high-impact structural anchors: hero statements, metric readouts (ROAS, conversion rates, cost-per-click), card headlines, and telemetry totals. It imparts an autonomous-agent cadence that feels engineered, high-tech, and decisive.
- **Geist** handles the rigorous workloads: multi-variable ad payloads, conversation transcripts, lead qualified tags, and user settings. Its low-contrast neutrality guarantees legibility across dense data tables and fast-scrolling message streams.
- Numerical readouts should consistently utilize tabular lining figures (`font-variant-numeric: tabular-nums`) to prevent jitter across active streaming analytics.

## Layout & Spacing

Layouts follow a 12-column fluid responsive grid anchored by generous micro-spacing and tight, structured metric clustering.

- **Desktop (>= 1280px)**: 12-column layout with `2rem` outer canvas padding and `1.25rem` gutters. Maximum application container width is constrained to `1440px` for optimal data density and control panel visibility.
- **Tablet (768px - 1279px)**: 8-column layout with `1.5rem` outer margins. Secondary sidebar panels convert to overlay drawers; telemetry modules wrap into 2x2 grids.
- **Mobile (< 768px)**: 4-column layout with `1rem` outer canvas padding. Metrics collapse into swipeable cards or vertical stacks with `space-sm` separation.

### Rhythm & Alignment
Spacing utilizes standard 4px/8px baselines. High-priority conversation streams and autonomous agent activity feeds prioritize vertical compactness (`space-sm` between messages), while analytic dashboards leverage `space-lg` to `space-xl` for sectional breathing room.

## Elevation & Depth

This system avoids heavy, muddy drop shadows in favor of bright architectural layering, hairline borders, and neon-tinged ambient backdrops.

- **Level 0 (Base)**: `#F8FAFC` flat canvas. Direct surface without elevation.
- **Level 1 (Card/Container)**: Background `#FFFFFF` enveloped by a crisp perimeter border `1px solid #E2E8F0` and an ultra-subtle ambient lift: `0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 1px 2px -1px rgba(15, 23, 42, 0.02)`.
- **Level 2 (Hover & Interactive Panels)**: Heightened card state: `0 10px 25px -5px rgba(15, 23, 42, 0.06), 0 8px 10px -6px rgba(15, 23, 42, 0.03)`, bordered by `#CBD5E1`.
- **Level 3 (Modals & Flyouts)**: Lifted navigation drawers and ad configuration modals: `0 20px 35px -10px rgba(15, 23, 42, 0.08), 0 1px 3px rgba(15, 23, 42, 0.04)`.
- **Level 4 (Luminous Glow / Autonomous Active State)**: Applied to live ad execution switches, conversion burst indicators, and active agent cards: `box-shadow: 0 0 0 1px rgba(37, 211, 102, 0.4), 0 8px 24px -4px rgba(37, 211, 102, 0.25)`.

## Shapes

The shape system is defined by pill-shaped geometries (level `3`) that soften technical density and create an approachable, high-conversion interface.

- **Pills (`rounded-full`)**: Applied to all primary CTA buttons, status badges, agent live chips, search bars, and filter pills.
- **Surface Panels (`rounded-xl` / 1.5rem to 2rem)**: Analytic dashboards, ad preview blocks, and telemetry containers utilize smooth rounded bounds that frame data without severe clinical edges.
- **Nested Controls (`rounded-lg` / 1rem)**: Internal input controls, segment buttons, and chat message clouds use balanced secondary radii that nest comfortably inside parent containers.
